# Conversa

Interface estática de uma plataforma de conversas/comunidades inspirada em fóruns modernos.

## Estrutura
- `index.html` — página principal
- `src/styles.css` — layout e responsividade
- `src/app.js` — interações locais

## Executar
Abra `index.html` diretamente no navegador. Não há dependências.

## Escopo
Frontend/demo apenas: sem autenticação, banco, API ou persistência real.
